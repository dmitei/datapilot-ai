# DataPilot AI

Telegram-бот для анализа финансовых показателей компаний. Пользователь загружает CSV или базу SQLite (`.db`) в личный чат и задаёт вопросы о данных. Бот возвращает числовые результаты и графики.

DataPilot AI строит пять отчётов: помесячная выручка, расходы и прибыль, топ-5 клиентов по годовой выручке и остаток кредитов по отраслям на конец года. Для помесячных показателей можно выбрать период и запросить итоговую сумму.

Бот написан на Python с aiogram, хранит данные в PostgreSQL и строит графики с Matplotlib. Для вопросов в свободной форме он может использовать LLM через OpenAI-совместимый API. У каждого пользователя свой набор данных, привязанный к его Telegram-аккаунту.
