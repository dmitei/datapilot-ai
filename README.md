# DataPilot AI

Telegram-бот для анализа помесячных данных компаний. Открой личный чат с ботом, отправь файл CSV или SQLite и задай вопрос. Бот вернёт значения и график PNG.

У каждого Telegram-аккаунта свой набор данных в PostgreSQL. Следующая успешная загрузка заменяет только данные отправителя. Можно пользоваться одним ботом с нескольких аккаунтов. Каждый увидит отчёты по своему файлу.

## Запуск на macOS

Понадобятся Python 3.12+ и запущенный [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/). В терминале из папки проекта выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp -n .env.example .env
docker compose up -d --wait db
```

Создай бота через [@BotFather](https://t.me/BotFather) командой `/newbot` и запиши токен в `BOT_TOKEN` в файле `.env`. Для первого запуска оставь `LLM_MODE=demo`.

```bash
python -m datapilot
```

1. В личном чате отправь `/start`.
2. Через **скрепку → Файл** отправь свой `.csv` или `.db`. Для пробы подойдёт [examples/example.db](examples/example.db).
3. После сообщения «База загружена» отправь `/revenue 2025` или напиши «Покажи общую выручку за первые 6 месяцев 2025».

Если используешь версию проекта, где раньше требовался `BOT_OWNER_ID`, просто загрузи файл в чат заново. При конфликте порта 5433 укажи свободный внешний порт в `compose.yaml` и такой же порт в `DATABASE_URL` в `.env`.

## Отчёты

| Команда | Что покажет бот |
| --- | --- |
| `/revenue 2025` | Выручка по месяцам |
| `/expenses 2025` | Расходы по месяцам |
| `/profit 2025` | Разница между выручкой и расходами по месяцам |
| `/top 2025` | Пять клиентов с наибольшей выручкой за год |
| `/loans 2025` | Остаток кредитов на конец декабря по отраслям |

Без указания года бот использует последний год в твоём файле. Для выручки, расходов и прибыли можно запросить часть года и итог за период. В деморежиме запросы распознаются по ключевым словам.

## Форматы файлов

Поддерживаются файлы до 5 МБ и до 20 000 строк показателей. Одна строка показателей соответствует одной компании и одному месяцу. Используй дату в формате `ГГГГ-ММ-01`, год от 1900 до 2099 и целые неотрицательные суммы в рублях.

### CSV

Сохрани файл в UTF-8. Разделитель — запятая или точка с запятой. Для одного `company_id` название и отрасль должны совпадать во всех строках.

```csv
company_id,name,industry,month,revenue_rub,expenses_rub,loan_balance_rub
1,Вектор Софт,ИТ,2026-01-01,2500000,1800000,4000000
1,Вектор Софт,ИТ,2026-02-01,2700000,1900000,3900000
```

### SQLite

| Таблица | Столбцы |
| --- | --- |
| `companies` | `id` (INTEGER, уникальный положительный ID), `name` (TEXT), `industry` (TEXT) |
| `monthly_finance` | `company_id` (INTEGER, ID из `companies`), `month` (TEXT), `revenue_rub`, `expenses_rub`, `loan_balance_rub` (INTEGER) |

Перед отправкой убедись, что все изменения сохранены в самом файле `.db`. Для годового отчёта по кредитам укажи остаток на конец декабря.

## Режим LLM

В `.env` задай `LLM_MODE=llm`, `LLM_API_KEY` и `LLM_MODEL`. При необходимости укажи `LLM_BASE_URL` с базовым адресом провайдера, например `https://api.openai.com/v1`. API должен поддерживать `POST /chat/completions` и поле `tools`.

Модель получает текст вопроса и схемы инструментов. Приложение проверяет выбранный инструмент, выполняет SQL и само формирует отчёт. Загруженные файлы и результаты SQL остаются в приложении и PostgreSQL. Команды вроде `/revenue` обрабатываются локально в обоих режимах.

## Демо в терминале и тесты

Для запуска без токена Telegram и ключа LLM оставь `LLM_MODE=demo`. Данные, импортированные из терминала, хранятся отдельно от наборов пользователей Telegram.

```bash
python -m datapilot --import-db examples/example.db
python -m datapilot "Покажи общую выручку за первые 6 месяцев 2025"
open report.png
```

```bash
python -m unittest discover -s tests -v
TEST_DATABASE_URL='postgresql://datapilot:datapilot@127.0.0.1:5433/datapilot' \
  python -m unittest discover -s tests -v
```

Вторая команда включает проверку импорта, отката, отчётов и изоляции пользователей в отдельной тестовой схеме PostgreSQL.

Останови бота через Ctrl+C. `docker compose down` остановит PostgreSQL и сохранит загруженные данные.
