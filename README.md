# DataPilot AI

Telegram-бот для аналитики синтетического портфеля корпоративных клиентов. PostgreSQL хранит помесячные показатели шести вымышленных компаний за 2024–2025 годы. Бот отправляет таблицу значений текстом и график PNG.

## Быстрый запуск на macOS

Понадобятся Python 3.12 или новее и запущенный [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/). Распакуй ZIP и открой в Терминале папку `datapilot-ai`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
docker compose up -d --wait db
python -m datapilot "Покажи динамику доходов по месяцам за 2024"
open report.png
```

Демо в терминале использует настоящую PostgreSQL из Compose и работает без токена Telegram и ключа LLM. Команда запуска печатает значения и сохраняет график в `report.png`. Путь можно задать через `--png figure.png`.

Если порт 5433 занят, измени внешний порт в `compose.yaml` и тот же порт в `DATABASE_URL` в `.env`. Если база уже есть, можно применить `init.sql` к отдельной пустой базе и указать её адрес в `.env`.

## Запуск в Telegram

1. Создай бота через [@BotFather](https://t.me/BotFather) командой `/newbot` и запиши полученный токен в `BOT_TOKEN` в `.env`.
2. В активированном окружении запусти `python -m datapilot`.
3. Открой чат с ботом, отправь `/start`, затем `/revenue 2024` или «Покажи кредитный портфель за 2025».

| Команда | Отчёт |
| --- | --- |
| `/revenue 2025` | Помесячная выручка |
| `/expenses 2025` | Помесячные расходы |
| `/profit 2025` | Помесячная прибыль как выручка минус расходы |
| `/top 2025` | Пять клиентов с наибольшей выручкой за год |
| `/loans 2025` | Остаток кредитов на конец декабря по отраслям |

Без указания года используется 2025. В демо обычные фразы распознаются по ключевым словам. Для каждого запроса поддерживается один отчёт и один год.

## Режим LLM

В `.env` задай `LLM_MODE=llm`, `LLM_API_KEY`, `LLM_MODEL` и при необходимости измени `LLM_BASE_URL`. Базовый адрес должен вести к OpenAI-совместимому API, поддерживающему `POST /chat/completions` и поле `tools`. Указывай базовый адрес, например `https://api.openai.com/v1`. Значение `LLM_MODEL` возьми из документации провайдера.

При обычном вопросе провайдер получает текст и схемы пяти функций. Приложение выполняет выбранный инструмент и само формирует ответ из результата SQL. Данные отчёта провайдеру не передаются. Команды с косой чертой работают без обращения к модели в обоих режимах. В `LLM_MODE=demo` приложение вообще не вызывает API модели.

## Тесты и остановка

```bash
python -m unittest discover -s tests -v
TEST_DATABASE_URL='postgresql://datapilot:datapilot@127.0.0.1:5433/datapilot' \
  python -m unittest discover -s tests -v
```

Первая команда проверяет маршрутизацию, контракт LLM с имитацией HTTP, валидацию и PNG. Вторая включает интеграционный тест пяти SQL-запросов для обоих лет. Для остановки бота нажми Ctrl+C. Команда `docker compose down` остановит базу и сохранит её данные.

Разбор потока данных и подготовка к техническому собеседованию находятся в [ARCHITECTURE.md](ARCHITECTURE.md).
